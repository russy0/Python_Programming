## 🔑 Key Concepts

### 변수명 규칙 (C와 동일)

- 숫자로 시작 x
- 예약어 사용 x
- 특수문자는 '_'만 가능
- 대소문자 구분

### 자료형

- int거의 제한이 없음
- float 부동소숫점 방식 사용
- 문자열 비교는 사전 순
- '\'로 이스케이프 가능

### 내장 함수

- **dir**: 객체가 가지고 있는 속성과 메소드 목록을 반환하는 파이썬 내장 함수
- **len**: 객체의 길이를 반환하는 파이썬 내장 함수

### 문자열 내장 함수

- **upper**: 모든 글자를 대문자로 변환
- **lower**: 모든 글자를 소문자로 변환
- **title**: 각 단어의 첫 글자를 대문자로 변환
- **lstrip**: 문자열의 왼쪽에 있는 공백 제거
- **rstrip**: 문자열의 오른쪽에 있는 공백 제거
- **strip**: 문자열의 좌우에 있는 공백 제거
- **find**: 문자열에서 가장 첫번째로 찾으려는 문자가 있는 인덱스 반환 (없으면 -1)
- **index**: 문자열에서 가장 첫번째로 찾으려는 문자가 있는 인덱스 반환 (없으면 에러)
- **count**: 문자열에서 글자가 몇개 있는 지 확인
- **startwidth**: 문자열이 해당 글자로 시작하는 지 확인
- **endwidth**: 문자열이 해당 글자로 끝나는 지 확인
- **replace**: 문자열에서 해당 단어를 다른 단어로 변경
- **isdigit**: 문자열이 숫자로만 이루어져 있으면 True (음수, 소수는 안됨)
- **isalpha**: 문자열이 알파벳으로만 이루어져 있으면 True
- **isalnum**: 문자열이 알파벳과 숫자로만 이루어져 있으면 True
- **isspace**: 문자열이 공백문자로만 이루어져 있으면 True
- **isupper**: 문자열이 대문자로만 이루어져 있으면 True
- **islower**: 문자열이 소문자로만 이루어져 있으면 True
- **split**: 기준 문자로 문자열을 나눔
- **join**: join 기준 문자을 이용해서 리스트를 문자열로

### 기타

- **in**: 문자열 안에 글자가 포함되는 지 확인 가능
